<p>Simple Voice Tool 是一个严肃的嗓音测量、分析与训练追踪工具，基于 Web Audio API。对着麦克风说话，即可获得基频、共振峰与能量的实时分析——完全离线，数据不出设备。</p>
<p><b>测量</b></p>
<ul>
<li>实时音高曲线：男声 / 女声 / 过渡区间着色，实时显示 Hz 与钢琴音名</li>
<li>三种测试模式：随意朗读、长音（静音判停 + Jitter）、音域滑音（声域图 VRP）</li>
<li>F1/F2 共振峰：元音空间散点图 + 共鸣训练目标区</li>
</ul>
<p><b>分析</b></p>
<ul>
<li>嗓音质量：Jitter、Shimmer、HNR、CPPS</li>
<li>四张图表共享时间轴，双滑块缩放 + 十字线读数；数据表视图（读屏友好，可复制 TSV）</li>
<li>用当前算法参数重算已存录音——调参无需重录</li>
<li>外部音频导入，走同一套离线分析管线</li>
</ul>
<p><b>追踪</b></p>
<ul>
<li>趋势图（平均基频、音域、MPT、CPPS）+ GitHub 式用声日记热力图</li>
<li>两条记录两两对比：Δ 指标表 + 音高曲线叠加</li>
<li>训练靶标达成率、基线记录自动对比</li>
<li>可选每日练习提醒</li>
</ul>
<p><b>隐私优先</b></p>
<ul>
<li>记录、音频与分析结果全部存于本机（IndexedDB）</li>
<li>完整 ZIP 备份恢复；可选加密云备份（你自己的 GitHub 仓库 / WebDAV / 本地文件夹）</li>
<li>「数据去向」面板如实说明每一类数据的边界</li>
</ul>
<p><b>可选 AI——自带接口</b></p>
<ul>
<li>训练建议、AI 周报与聊天助手：接入你自己的 OpenAI 兼容 / Anthropic 接口</li>
<li>仅上传聚合统计指标——从不发送音频与原始曲线；每次请求在应用内可查</li>
<li>不启用任何 AI 功能，应用也完整可用</li>
</ul>
<p><b>多端</b></p>
<ul>
<li>可安装为 PWA；提供安卓 APK 与 Windows 安装包</li>
<li>键盘快捷键；五种语言（English、简体中文、繁體中文、日本語、文言）</li>
</ul>
