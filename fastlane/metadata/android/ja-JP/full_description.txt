<p>Simple Voice Tool は、Web Audio API ベースの本格的な声の測定・分析・トレーニング記録ツールです。マイクに向かって話すだけで、ピッチ・フォルマント・エネルギーをリアルタイムで分析します。完全オフライン、データは端末の外に出ません。</p>
<p><b>測定</b></p>
<ul>
<li>リアルタイム音高カーブ：男性声 / 女性声 / 過渡域の色分けと音名表示</li>
<li>3 つのテストモード：自由朗読、ロングトーン（無音で自動停止 + Jitter）、グリッサンド（声域プロファイル）</li>
<li>F1/F2 フォルマント：母音空間の散布図と共鳴トレーニングの目標領域</li>
</ul>
<p><b>分析</b></p>
<ul>
<li>声の質：Jitter、Shimmer、HNR、CPPS</li>
<li>全グラフで共通の時間軸、ズームと十字カーソル読み取り、データテーブル表示（TSV コピー可）</li>
<li>保存した録音を最新のアルゴリズムで再分析——録り直しは不要</li>
<li>外部音声ファイルも同じオフライン解析パイプラインで処理</li>
</ul>
<p><b>記録</b></p>
<ul>
<li>トレンドグラフ（平均 F0、音域、MPT、CPPS）と GitHub 風の練習ヒートマップ</li>
<li>2 件の記録を比較：Δ 指標表 + 音高カーブの重ね合わせ</li>
<li>トレーニング目標の達成率、ベースライン記録との自動比較</li>
<li>毎日の練習リマインダー（任意）</li>
</ul>
<p><b>プライバシー最優先</b></p>
<ul>
<li>記録・音声・解析結果はすべて端末内（IndexedDB）に保存</li>
<li>ZIP バックアップと復元、暗号化対応のクラウドバックアップ（自分の GitHub リポジトリ / WebDAV / ローカルフォルダ）</li>
<li>「データの行き先」パネルで扱いを正直に説明</li>
</ul>
<p><b>任意の AI——キーは自分で</b></p>
<ul>
<li>トレーニングアドバイス・週次レポート・チャットアシスタントに、自分の OpenAI 互換 / Anthropic エンドポイントを利用</li>
<li>送信するのは集計済みの統計指標のみ——音声や生データは送信しません。全リクエストをアプリ内で確認可能</li>
<li>AI 機能を使わなくてもすべての機能が完全に動作します</li>
</ul>
<p><b>マルチプラットフォーム</b></p>
<ul>
<li>PWA としてインストール可能。Android APK と Windows インストーラーを提供</li>
<li>キーボードショートカット、5 言語対応（English、简体中文、繁體中文、日本語、文言）</li>
</ul>
