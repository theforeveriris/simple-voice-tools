<p>Simple Voice Tool 是一個嚴肅的嗓音測量、分析與訓練追蹤工具，基於 Web Audio API。對著麥克風說話，即可獲得基頻、共振峰與能量的即時分析——完全離線，資料不出裝置。</p>
<p><b>測量</b></p>
<ul>
<li>即時音高曲線：男聲 / 女聲 / 過渡區間著色，即時顯示 Hz 與鋼琴音名</li>
<li>三種測試模式：隨意朗讀、長音（靜音判停 + Jitter）、音域滑音（聲域圖 VRP）</li>
<li>F1/F2 共振峰：母音空間散點圖 + 共鳴訓練目標區</li>
</ul>
<p><b>分析</b></p>
<ul>
<li>嗓音品質：Jitter、Shimmer、HNR、CPPS</li>
<li>四張圖表共享時間軸，雙滑桿縮放 + 十字線讀數；資料表檢視（讀屏友善，可複製 TSV）</li>
<li>以目前演算法參數重算已存錄音——調參無需重錄</li>
<li>外部音訊匯入，走同一套離線分析管線</li>
</ul>
<p><b>追蹤</b></p>
<ul>
<li>趨勢圖（平均基頻、音域、MPT、CPPS）+ GitHub 式用聲日記熱力圖</li>
<li>兩條記錄兩兩對比：Δ 指標表 + 音高曲線疊加</li>
<li>訓練靶標達成率、基線記錄自動對比</li>
<li>可選每日練習提醒</li>
</ul>
<p><b>隱私優先</b></p>
<ul>
<li>記錄、音訊與分析結果全部存於本機（IndexedDB）</li>
<li>完整 ZIP 備份恢復；可選加密雲端備份（你自己的 GitHub 儲存庫 / WebDAV / 本機資料夾）</li>
<li>「資料去向」面板如實說明每一類資料的邊界</li>
</ul>
<p><b>可選 AI——自帶介面</b></p>
<ul>
<li>訓練建議、AI 週報與聊天助手：接入你自己的 OpenAI 相容 / Anthropic 介面</li>
<li>僅上傳聚合統計指標——從不傳送音訊與原始曲線；每次請求在應用內可查</li>
<li>不啟用任何 AI 功能，應用也完整可用</li>
</ul>
<p><b>多端</b></p>
<ul>
<li>可安裝為 PWA；提供 Android APK 與 Windows 安裝包</li>
<li>鍵盤快捷鍵；五種語言（English、简体中文、繁體中文、日本語、文言）</li>
</ul>
