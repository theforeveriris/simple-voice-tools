# Simple Voice Tool 使用说明

一款基于 Web Audio API 的语音测试与追踪应用，为跨性别声音训练（女性化 / 男性化）与日常嗓音健康设计。

**隐私承诺**：所有录音与统计数据仅保存在你自己的设备（浏览器 IndexedDB），不上传任何服务器；训练建议选择「大模型判断」时，仅把统计指标（不含音频）发送到你自己填写的接口。

---

## 首次打开

- 第一次打开会进入引导页：选择训练方向（女性化 / 男性化 / 其他）与年龄段，应用据此铺底训练靶标等参数，并挑选主题外观——都可以之后在设置中修改；
- 打开应用，允许麦克风权限；
- 到「测试」页，短按底部圆球开始录音，再按一次结束；
- 录完自动进入「分析」页查看报告（可在 设置 → 配置 中修改）。

## 三种测试模式（长按圆球切换）

- **朗读**：任意读一段文字。反映日常说话状态：音高、语调起伏、连贯度；
- **长音**：舒服地发一个「a」持续到底，发声后静音约 1 秒自动结束。测量气息与控制力（MPT / 稳定度 / 衰减），也是嗓音健康的净化样本；
- **滑音**：从低到高缓慢滑唱 20 秒。绘制声域图（VRP 热图），看真实音域边界。

## 分析页

- **概览与统计表**：音高（均值 / 中位数 / P10–P90 工作音域 / 标准差）、共振峰（共鸣）、能量、嗓音质量（Jitter / Shimmer / HNR / CPPS）四组；
- **图表**：音高 / 共振峰 / 能量 / 语谱图，共享时间区间（拖动任一图下方的窗口联动缩放，统计随之重算）；
- **回放**：保存过音频的记录可回放，播放头同步到各图表；
- **基线 Δ**：在 设置 → 配置 → 训练 中钉选基线后，自动显示与基线的差值；
- **训练建议**：规则判断（本地生成）或大模型判断（AI），见下文 AI 功能；
- **共振峰目标区**：设定目标 F1/F2 后，元音散点图叠加目标矩形并统计落点命中率；
- **重新分析**：算法参数更新后，可用当前参数重算历史记录（见下文高级）；
- **分享 / 导出**：右上角分享卡（多种卡面样式 PNG）、帧级数据 CSV、备注。

## AI 助手

- 底部栏或设置可进入「助手」页：与 AI 对话式地回顾你的测试历史、追问指标含义；
- 助手能看到你完整的测试记录（仅统计指标与备注，不含音频）；
- 对话保存在本机，可随时清除；配合 设置 → 大模型 使用。

## 历史页

- **列表**：按备注 / 日期 / 模式搜索；长按进入多选，选两条可「对比」（指标 Δ + 音高曲线叠加 + 元音空间叠加）；删除可撤销；
- **趋势**：用声日记热力图（打卡）、平均基频与音域带趋势图（可按模式过滤，长音与朗读不可比）、**AI 周报**（聚合近 7 天生成总结）；
- **快捷键**：桌面端支持键盘快捷导航（设置内可查看快捷键说明）。

## 训练相关（设置 → 配置 → 训练）

- **训练方向与年龄段**：女性化 / 男性化 / 其他，儿童 / 成人 / 长者——影响默认靶标与参考口径；
- **训练靶标**：设定目标基频区间（新装默认 120–220 Hz 中性区间，按训练方向铺底的预设见参数说明书）后，测试页实时显示偏差与达成率。达成率长期 <20% 说明目标过高（先调低），>90% 可以加难度；
- **基线记录**：开始系统训练当天录一条作为基线，之后每条记录自动与它对比；建议每月滚动更新一次；
- **共振峰目标区**：设定目标 F1/F2 中心与半径，用于元音落点命中率；
- **练习提醒**（配置 → 练习提醒）：每日固定时间本地通知提醒录一条；当天已有记录则不打扰。注意：提醒在应用打开或后台运行时生效，应用被完全关闭后无法唤醒（无推送服务的平台限制）。

## AI 功能

- **大模型**（设置 → 大模型）：配置任意 OpenAI 兼容接口（Base URL / API Key / 模型 ID），支持多个配置档与 Anthropic 接口，可「测试连接」；仅统计指标出本机，请使用可信接口；
- **提示词**（设置 → 提示词）：给 AI 建议追加补充规则（如「优先评估共鸣」），或整体覆写内置提示词；
- **AI 周报**：历史页趋势视图底部，一键把近 7 天聚合统计交给大模型出周总结；
- **AI 助手**：见上文「AI 助手」一节；
- **AI 翻译**：界面里缺的翻译可由大模型自动补齐（设置 → 语言）。

## 高级（设置 → 高级）

- **分析页语谱图 / 实时频谱**：更多可视化（额外耗电）；
- **音高算法对比**：YIN 之外可选 pYIN / MPM，并可叠加对比各算法结果；
- **自定义音区边界**：四个分界点划分五个音区，适配变声期、童声、低音女声；
- **实时元音落点 / 实时声域图 / 实时语谱**：说话时实时看 F1/F2 在元音空间的移动、音域包络与频谱，监听模式不保存录音；
- **算法参数微调**：YIN 阈值、音高上下限、预加重、LPC 阶数、共振峰搜索窗等；
- **重新分析**：参数变化后批量重算历史记录的统计指标；
- **导入音频分析**：把外部录音（手机录音、微信语音）拖入分析，安装为应用后支持系统「分享到」。

## 数据管理

- 导出 / 导入 JSON（全量记录）、设置单独导出、帧级 CSV、交互式 HTML 报告、Praat 格式；
- 本地自动备份：选择文件夹后按天写入（实验性）；
- GitHub 云备份：Device Flow 连接自己的私有仓库；
- WebDAV 云备份：连接任意 WebDAV 服务（坚果云等）；
- 备份加密：为云备份设置口令（AES 加密），并支持自动锁定；
- 载入示例数据（无麦克风体验用）、清除全部数据；
- 数据流向说明（隐私政策）：[privacy-policy.md](privacy-policy.md)，也可在 设置 → 关于 查看。

## 外观与语言

- 主题：莫奈取色（跟随主题色相滑条）、跨性别骄傲旗固定配色，或自定义背景图片；浅色 / 深色 / 跟随系统；
- 彩蛋：特定声线触发主题音染与音量呼吸等效果；
- 界面语言：简体中文、繁體中文、English、日本語（后两者为机器翻译）、文言；支持自定义词条与 AI 补翻。

## 必要说明（请务必阅读）

1. **不构成医学诊断**。所有参考范围来自常见嗓音科学文献的近似值，未经临床验证；若出现喉痛、压迫感、持续嘶哑，立即停止训练并就医。
2. **数据只能和自己比**。受麦克风、距离、环境影响巨大；请固定设备与录音条件做纵向追踪，换设备后请重新录基线。
3. **嗓音质量四项是安全线**：Jitter / Shimmer / HNR / CPPS 变差 = 声带在受累。四项一起变差说明练习过量，先休息；单次异常没有意义，看趋势。
4. **长音与朗读的数据不可比**，趋势图请按模式过滤。
5. **AI 建议由大模型生成**，仅供参考，不构成医学建议；分析标准与参数说明书的口径一致，可在提示词页补充你自己的规则。
6. **录音属于敏感个人信息**，本应用不联网上传；如担心设备被翻看，可在设置中为云备份启用口令加密，或考虑浏览器隐私模式使用（数据不落盘）。
7. 响度未经绝对声压校准（dBFS），只反映相对强弱。

## 常见问题

- **嗓音质量显示「—」**：未开启「保存录音音频」，或该记录早于该功能；
- **提示数据无效**：录音太短、有效发声占比过低、响度异常（离麦太远或削波）；
- **AI 相关功能不可用**：先到 设置 → 大模型 填写接口并「测试连接」；
- **想看某个参数的详细解读**：仓库 `documentation/PARAMETERS-GUIDE.md` 有全部参数的物理含义、参考区间与训练意义。
