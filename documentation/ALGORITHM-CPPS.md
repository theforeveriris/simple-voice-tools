# 算法 · 倒谱峰突出度（CPPS）

平滑倒谱峰突出度（Cepstral Peak Prominence, Smoothed）是 Jitter / Shimmer / HNR 之外
临床常用的第四项嗓音质量指标。它的核心优势：**对连续语音（朗读）同样稳健**——
Jitter/Shimmer 依赖逐周期检测，在连续语流中易受协同发音和音段边界干扰，
而 CPP 只要求信号存在谐波结构，因此朗读、长音两种模式都能给出可比的数值。

## 一、倒谱是什么

对信号做 FFT 得到频谱 `X(f)`，取对数幅度谱 `log|X(f)|`，再做一次逆变换
（IFFT），得到的域称为**倒谱域（cepstrum）**，其横轴称为 **quefrency**（单位是样本/秒，
与"周期"同量纲）。

直觉：嗓音频谱是一根根等间隔（间隔 = 基频）的谐波梳。取对数后，谐波梳的包络
（声道共鸣特性）与梳齿细节（基音周期）相乘变为相加；IFFT 之后，**梳齿细节集中在
quefrency = 1/F0 处形成一个峰**，而包络变化平缓、分布在低 quefrency 区。

于是「这个峰比倒谱包络背景高出多少 dB」就度量了**谐波结构的显著程度**：

- 谐波清晰、周期性强（正常嗓音）→ 峰高 → CPP 大
- 噪声成分高、谐波被淹没（气息声、嘶哑）→ 峰矮 → CPP 小

## 二、逐帧计算（本实现口径）

对每帧（40ms 窗 / 10ms 帧移，能量过活跃门限 `activeGateDb`（默认 −50dB，实验性可调）的帧参与）：

1. **加窗**：汉宁窗，零填充至 2 的幂长度；
2. **FFT → 功率谱 → 取 10·log10**（下限 −100dB 防止 log(0)）；
3. **实倒谱**：对数谱保持共轭对称，正变换后除以 N 即得（实偶序列）；
4. **搜索峰值**：在 quefrency 区间 `[sr/cppsF0Max, sr/60]`（对应基频 60 – `cppsF0Max` Hz；`cppsF0Max` 默认 500，实验性可调 300–1000；下限 60 Hz 固定）内找倒谱最大值；
5. **回归线基线**：对同区间倒谱值做最小二乘直线拟合，帧级
   `CPP = 峰值 − 回归线在峰值 quefrency 处的取值`。

回归线扣除的是「声道包络整体倾斜」的贡献，使数值主要反映谐波/噪声对比度，
这是 Hillenbrand (1994) 的经典口径。

## 三、从帧级 CPP 到 CPPS

- **时间平滑**：帧级 CPP 序列做 `cppsSmoothFrames`（默认 5 帧 = 50ms，实验性可调 1–15）
  的**以当前帧为中心**的滑动平均，抑制相邻帧的倒谱峰跳动（"Smoothed" 的由来）；
- **分布统计**：`CPPS = 平滑后帧序列的均值 − 标准差`。

减标准差的原因：正常嗓音帧间 CPP 稳定（std 小，减得少）；障碍嗓音帧间波动大
（std 大，数值进一步压低），对异常更敏感。

## 四、数值解读（仅供参考，非医学诊断）

| CPPS（连续语音） | 提示 |
| --- | --- |
| ≥ 10 dB | 谐波结构清晰，常见于健康嗓音 |
| 4 – 10 dB | 中等，可能与轻中度嗓音障碍重叠 |
| < 4 dB | 谐波结构不显著，噪声成分高（研究常用 <4dB 作为声嘶筛查线） |

注意：CPPS 受录音设备、增益、环境噪声与语料影响，纵向对比（同设备、同模式、
不同日期）比横向绝对值更有意义。长音模式下的 CPPS 通常高于朗读模式（元音的
谐波结构比语流更纯净），两种模式之间不要直接比较。

## 五、实现要点（src/lib/audio/cpp.ts）

- FFT 为自写的基-2 迭代实现（位反转 + 蝶形），无第三方依赖；`fft` 已导出复用
  （离线管线的语谱图频谱共用同一实现）；
- 实倒谱利用「对数谱共轭对称 → 正变换除以 N」的性质，避免显式共轭逆变换；
- 帧级统计最少需要 10 个有效帧，不足时返回 `null`（显示为「—」）；
- 结果四舍五入到 0.1 dB 存储；
- 与 Jitter/Shimmer/HNR 一样，仅在开启「保存录音音频」时可用，
  旧记录无此字段。
