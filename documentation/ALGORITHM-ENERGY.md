# 能量分析 · RMS 电平

> 源码：`src/lib/audio/pitch.ts` 中的 `rmsDb()` ｜ 每帧计算一次（约 60fps）

## RMS 与分贝

能量曲线反映的是"声音有多大"。对一帧 4096 个时域样本 `x`：

$$x_{rms} = \sqrt{\frac{1}{N}\sum_{i=0}^{N-1} x[i]^2}$$

再换算为分贝（声学惯例，相对于满幅 1.0）：

$$db = 20 \cdot \log_{10}(x_{rms})$$

- 满幅正弦波（rms ≈ 0.707）≈ -3 dB；
- 安静房间里麦克风底噪通常在 -60 ~ -45 dB；
- 静音（rms < 1e-5）钳位到 **-90 dB**，避免 log(0)。

人耳对响度的感知近似对数，dB 刻度下曲线的起伏才符合直觉；纵轴范围固定为
`[-90, 0]`（`ENERGY_AXIS`），不同录音之间可以直接比较。

## 门限体系

能量不只是展示，它同时是整个分析流水线的**有声/无声（VAD）开关体系**——
三道独立门限，其中两道实验性可调（设置 → 实验性功能 → 算法参数）：

| 门限 | 默认值 | 用途 |
| --- | --- | --- |
| 发声门限 `voicedGateDb` | 帧电平 > **-55 dB** | 低于此值跳过音高检测，省算力且避免噪声误检（可调 -70…-40） |
| 活跃门限 `activeGateDb` | 帧电平 ≥ **-50 dB** | 响度统计 / Jitter·Shimmer·HNR / CPPS 的静音判据（可调 -70…-30） |
| LPC 门限（固定） | 帧电平 > **-52 dB** | 能量太低时自相关病态，共振峰不可信（未参数化） |
| 长音静音判停（固定） | 帧电平 ≤ **-50 dB** 计入静音 | 长音模式"发声后静音 1 秒自动停止"的静音判定（未参数化） |
| 显示刻度 | -90 ~ 0 dB | 图表纵轴（`ENERGY_AXIS`） |

门限是固定/用户可调常数而非自适应值：底噪会随设备变化，但语音帧通常高出底噪
15dB 以上，固定门限在绝大多数场景下足够稳健，也避免了自适应门限在"持续背景音"
场景下把噪声误判为人声的问题。门限经 `lib/audio/algoParams.ts` 单例同步到
实时循环、离线管线与 Worker。

## 展示与存储

- **测试页能量图**：实时电平线 + 垂直渐变面积，随 12 秒滚动窗口刷新；
- **分析页能量图**：同一画笔的静态模式，配合时间轴缩放查看任意区间；
- **时间轴选择器的密度预览条**：把整段 rmsDb 按时间分 90 桶、每桶取**峰值**
  （而非均值，更直观地保留瞬态尖峰），归一化后作为条高；
- **统计**：平均响度、峰值响度进入统计表；有效发声占比（**检出基频的帧比例**，
  即 F0 > 0 的帧占比）进入"能量与时长"分组——注意它衡量的是"有声连贯度"，
  电平门限只用于筛选平均响度的统计样本。

## 存储格式

存储时电平值保留 1 位小数（`Math.round(db * 10) / 10`），约 30Hz 采样率降采样后
写入 `AnalysisRecord.series.rmsDb`。负 dB 值均为有限小数，JSON 体积可控。
