# 音高检测 · YIN 算法

> 源码：`src/lib/audio/pitch.ts` ｜ 实时运行于每一帧（约 60fps），单帧约 0.75M 次乘加运算

## 为什么选择 YIN

项目早期的音高检测基于**频谱谐波匹配**：把每个候选音符的谐波位置在 FFT 频谱上打分，
取得分最高者。它有两个致命问题：

1. **半音量化**：候选频率直接取自十二平均律音高表，输出频率永远吸附在音符网格上
   （例如 196.00Hz 而不是真实的 193.8Hz），画出来的音高曲线是台阶状的；
2. **基频缺失敏感**：电话语音、低音歌手的基频能量弱，谐波打分容易错到倍频上。

YIN（Alain de Cheveigné & Hideki Kawahara, 2002）是时域算法，直接在波形上找重复周期，
输出**连续、亚赫兹级精度**的基频，并且自带周期性置信度——非常适合绘制平滑曲线。

## 算法原理

YIN 的输入是一帧时域信号 `x`（本项目取 AnalyserNode 的 4096 样本中的一半作为分析窗）。

### 第 1 步：差分函数 d(τ)

$$d(\tau) = \sum_{i=0}^{W-1} (x[i] - x[i+\tau])^2$$

直觉：如果信号以 τ 为周期，那么 `x[i] ≈ x[i+τ]`，差分在 τ 的整数倍处接近 0。
W 取帧长的一半（2048 样本缓冲 → W = 1024），τ 的搜索范围由频率上下限决定：

- τ_min = fs / maxHz ≈ 44100 / 600 ≈ **74**（对应 600Hz）
- τ_max = fs / minHz ≈ 44100 / 60 ≈ **735**（对应 60Hz）

### 第 2 步：累积均值归一化（CMND）

$$d'(\tau) = \frac{d(\tau) \cdot \tau}{\sum_{j=1}^{\tau} d(j)}$$

裸的差分函数有一个经典陷阱：在真实周期 τ₀ 的 **2τ₀、3τ₀** 等处，d(τ) 同样很小，
甚至经常比 τ₀ 处更低——直接取全局极小会得到**八度向下**的错误。

CMND 把每个点的差分除以"它之前所有差分的累积平均"：在首个真实周期处 d' 会降到
远低于 1，而在次周期处由于累积平均已经被之前的低谷拉低，d' 不会显著低于 1。
这一步是 YIN 抗八度错误的核心。

### 第 3 步：绝对阈值搜索

从 τ_min 向后扫描 d'，找到**第一个低于阈值 0.14 的点**后，继续走到该谷底的局部极小。
- 若整段扫描的最小值仍 > 0.45，说明波形没有明显周期性（噪声/无声），返回 null；
- 置信度输出 `prob = 1 - bestVal`。

"第一个低于阈值的谷"而非"全局最低谷"是刻意的：语音是非平稳信号，取更深的次周期谷
反而更容易跳到倍频。

### 第 4 步：抛物线插值

τ 只能取整数样本，分辨率受限于 fs/τ（在 200Hz 附近约 2~3Hz 一跳）。对极小点及其两个
邻点做抛物线拟合，取抛物线顶点作为更精确的 τ：

$$\tau^* = \tau + \frac{d'(\tau-1) - d'(\tau+1)}{2\,(d'(\tau-1) - 2d'(\tau) + d'(\tau+1))}$$

最终 `freq = sampleRate / τ*`，精度达到亚赫兹级。

## 参数一览

| 参数 | 值 | 说明 |
| --- | --- | --- |
| 分析缓冲 | 4096 样本 | AnalyserNode fftSize，时域数据 |
| YIN 窗长 W | 1024 | 缓冲的一半 |
| 频率范围 | 60 – 600 Hz | 覆盖人声基频（男低到女高、假声） |
| CMND 阈值 | 0.14 | 越小越严格，误检越少但哑音增多 |
| 放弃阈值 | 0.45 | 超过则判为无声帧 |
| 无声门限 | 帧电平 > -55 dB | 能量太低直接跳过检测（见能量分析文档） |

## 源码导读

`src/lib/audio/pitch.ts`：

- `detectPitchYin(samples, sampleRate, minHz, maxHz)` —— 主函数，四个步骤与上文一一对应：
  1. 双重循环计算 `diff[]`（差分函数）；
  2. 单循环计算 `cmnd[]`（累积均值归一化）；
  3. 扫描寻找第一个低于阈值的谷，找不到返回 `null`；
  4. `betterTau` 抛物线插值，换算频率并夹紧到有效范围。
- `rmsDb(samples)` —— 帧能量计算，被录音引擎同时用于能量曲线与有声门限。

## 复杂度与实时性

- 时间复杂度 O(W · τ_max) ≈ 1024 × 735 ≈ **0.75M 次乘加/帧**；
- 60fps 下约 45M 次运算/秒，现代桌面浏览器单帧耗时 < 2ms；
- 内存：每帧两个 Float32Array（约 735 × 4B × 2），可忽略。

## 局限与改进方向

- 强噪声下仍可能出现倍频/半频跳跃，可用中值滤波后处理；
- 哑音段（气声、擦音）返回 null，曲线断开是预期行为；
- 如需更高稳健性，可升级为 pYIN（对阈值做贝叶斯概率化）或 MPM；
- 若未来支持歌唱微调显示，可将置信度 prob 一并存储用于曲线透明度编码。
