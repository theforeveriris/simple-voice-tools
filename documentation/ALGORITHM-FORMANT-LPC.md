# 共振峰提取 · LPC 线性预测编码

> 源码：`src/lib/audio/formants.ts` ｜ 每 2 帧计算一次（约 30Hz），输出经指数平滑

## 共振峰是什么

人声的激励源是声带振动（基频 + 谐波列），而**声道**（咽喉—口腔—鼻腔的管道）是一个
谐振腔，会对谐波做幅度加权——某些频段被共鸣放大，这就是**共振峰（Formant）**。

- **F1**（第一共振峰，约 200–1100Hz）与开口度/舌位高度相关：嘴巴张得越大，F1 越高；
- **F2**（第二共振峰，约 700–3400Hz）与舌位前后相关：舌位靠前（如 /i/）F2 高，
  靠后（如 /u/）F2 低。

F1/F2 平面基本决定了元音音色，是语音学、语言训练、口音分析的核心特征。
它们与基频无关：同一元音，男声女声的 F1/F2 大体相同，但 F0 不同。

## 为什么用 LPC

声道是一个**全极点滤波器**（谐振腔只放大、不吸收）。LPC（Linear Predictive Coding）
用全极点模型 `1/A(z)` 去拟合短时语音谱，极点的位置就是共振峰。这是语音分析几十年的
标准方法，计算量小、频率精度高，适合浏览器实时运行。

## 信号链总览

```
时域帧 (4096 @ 44.1kHz)
  → 1. 预加重 (0.97)
  → 2. 抗混叠低通 + 4x 抽取 (→ 11.025kHz, 1024 样本)
  → 3. 归一化 + 汉明窗
  → 4. 自相关 (阶数 p = 13)
  → 5. Levinson-Durbin 求 LPC 系数
  → 6. Durand-Kerner 多项式求根
  → 7. 根筛选 (单位圆内、带宽、频段)
  → 8. 挑选 F1 / F2
```

### 1. 预加重

$$y[n] = x[n] - 0.97\,x[n-1]$$

口唇辐射使语音谱整体每倍频程 +6dB 滚降，高频能量远弱于低频。预加重（一阶高通）
抵消这个倾斜，让谱包络变平——LPC 对平谱的拟合最稳定，否则低频极点会"吃掉"高频极点。

### 2. 抗混叠低通 + 4 倍抽取

LPC 阶数的经验公式是 **p ≈ 2 + fs/1000**（每个 1kHz 频段大约需要一对极点）。
44.1kHz 直接做需要 46 阶， roots 数量多、噪声根多、计算大。
先用 RBJ 双二阶巴特沃斯低通（截止 `min(4500, fs2×0.42)` ≈ 4.6kHz）抗混叠，
再每 4 个样本取 1 个，得到 fs2 ≈ 11kHz —— 足够覆盖 F3 以下频段，p 降到 **13**。

### 3. 归一化 + 汉明窗

幅度归一化到峰值 1（LPC 只关心谱形状，与音量无关），加汉明窗抑制帧截断带来的
频谱泄漏，否则自相关被旁瓣污染。

### 4. 自相关

$$r[k] = \sum_{i=0}^{N-1-k} w[i]\,w[i+k], \quad k = 0..p$$

自相关法求 LPC 的好处：只要 r[0] > 0，解出的多项式保证稳定（所有极点在单位圆内），
这正是我们想要的——共振峰本来就是稳定谐振。

### 5. Levinson-Durbin 递推

解 Yule-Walker 方程求预测系数 `a[1..p]`，复杂度 O(p²) 远低于矩阵求逆。
递推中若某级反射系数 |k| ≥ 1，说明这一帧数值不稳定（接近纯噪声），直接放弃本帧。

### 6. 多项式求根（Durand-Kerner）

LPC 谱的极点即多项式 `A(z) = 1 - a₁z⁻¹ - … - a_p z⁻ᵖ` 的根。
Durand-Kerner（Weierstrass）法同时迭代全部复根，实现极简：

$$z_i \leftarrow z_i - \frac{P(z_i)}{\prod_{j \neq i} (z_i - z_j)}$$

初值取 (0.4 + 0.9i) 的幂，迭代 60 次或收敛到 1e-10。

### 7. 根 → 共振峰候选

对每个根 `z`（复数）：

- 仅保留 **|z| < 1** 的根（单位圆内 = 稳定极点）；
- 频率 `f = arg(z) · fs2 / 2π`
- 带宽 `bw = -ln|z| · fs2 / π`（模长越接近 1，谐振越尖锐）

筛选：`f ∈ [150, 4800]` 且 `bw < 700Hz`。共振峰是窄带谐振，宽带根来自噪声或鼻音零点。

### 8. 挑选 F1 / F2

- **F1** = 频率落在 `[200, 1100]` 的最低候选；
- **F2** = 频率落在 `[max(F1+150, 700), 3400]` 的最低候选；
- 找不到则该帧对应值记为 null（曲线上断开）。

### 9. 时域平滑

帧间用指数平滑抑制抖动：`smooth = smooth × 0.45 + raw × 0.55`。
**无声帧会重置平滑链**——否则哑音两侧的共振峰会跨段拉出一条假直线。

## 源码导读

`src/lib/audio/formants.ts`：

- `lowPassBiquad(samples, sampleRate, cutoff)` —— RBJ cookbook 双二阶低通，返回滤波后序列；
- `levinsonDurbin(r, order)` —— 自相关 → LPC 系数，含 |k|≥1 稳定性保护；
- `polyRoots(c)` —— Durand-Kerner 全复根迭代（首一多项式）；
- `extractFormants(samples, sampleRate, rms)` —— 主函数，按上文信号链顺序组织，
  返回 `{ f1, f2 }`（未检出为 null）。

录音引擎（`src/lib/audio/recorder.ts`）每 2 帧调用一次 `extractFormants`，
并对结果做指数平滑后写入缓冲。

## 复杂度与实时性

- 自相关 O(N·p) ≈ 1024 × 13 ≈ 13K 次乘加；
- 求根 O(迭代 × p²) ≈ 60 × 169 ≈ 10K 次复数运算；
- 单帧合计 < 1ms，30Hz 调用毫无压力。

## 局限与改进方向

- **全极点假设**：鼻音、边音（/m/ /n/ /l/）声道有零点，LPC 谱会失真，F1/F2 仅供参考；
- 清辅音（/s/ /f/）是噪声激励，无共振峰概念，帧输出 null 是正确行为；
- 复合元音/双元音的滑行段，单极点对模型会产生偏移，表现为曲线快速滑动；
- 改进方向：LPC 包络峰值 picking（对 1/|A(e^jω)| 找峰）作为求根法的对照；
  或用加权 LPC（WLP）抑制高频噪声根。
