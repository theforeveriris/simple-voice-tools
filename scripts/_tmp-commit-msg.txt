feat(android): quick-settings tiles for record / history / settings

- RouteTileService (TileService base, API 24+): click opens the app via
  the same simplevoicetool:// deep-link the app shortcuts use, so cold
  start queues the route for getInitialRoute() and warm start pushes the
  shortcutRoute event - zero new Web-side code
- three manifest services with routes hardcoded in trivial subclasses
  (RecordTileService / HistoryTileService / SettingsTileService); labels
  follow system language via the existing shortcut_* strings
- visibility and ordering are user-configurable in the system tile editor
  (standard TileService behavior); pre-API-24 devices never instantiate
  the services, so minSdk 23 stays unchanged
- compiled against the project SDK (gradle :app:compileDebugJavaWithJavac
  passes; only the intentional pre-29 startActivityAndCollapse deprecation
  warning remains)
- GUIDE-CAPACITOR: new quick-settings tiles section
