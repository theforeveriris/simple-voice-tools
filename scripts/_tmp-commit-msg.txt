feat(garden): voice flowers - stats bloom into generative art

- lib/flower.ts: pure mapping record -> Flower params (unit-tested, 12 cases):
  petals = harmonic entropy from the spectrogram bands (fallback: band-mix
  diversity), shape = F1/F2 (low F1 = narrow petals, high F2 = long + tilted),
  hue = male/female band mix (cold blue -> warm pink), stem = MPT for
  sustained records, core glow = CPPS; graceful degradation everywhere -
  no audio / no formants never fails to produce a flower
- FlowerSvg: organic bezier petals (quadratic curves), translucent layering,
  hue jitter derived from record id so same-band flowers differ; pure-param
  SVG assembly
- GardenView: history page gains a third view "Garden" - all records bloom
  in a date-ordered bed (2/4-col grid), mode filter, tap a flower for a
  detail sheet (big flower + "which petal is what" facts + jump to analysis)
- shareCard: 5th style "flower" - large canvas-painted flower + key stats
  line + legend + QR; ShareCardSheet option added
- i18n x5 locales; 192 tests green
